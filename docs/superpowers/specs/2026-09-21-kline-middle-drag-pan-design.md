# K线图中键拖动平移 — 设计文档

日期：2026-09-21
状态：已批准

## 需求

【股票详情】页 K 线图新增交互：按住鼠标中键（滚轮键）左右拖动，可平移 K 线视图到指定区域查看。

## 背景

K 线图为纯 Canvas 自绘实现（`web/static/js/kline_chart.js`，约 1331 行），视图窗口由 `state.viewStart/viewEnd` 控制。现有鼠标交互：

| 事件 | 行为 |
|---|---|
| 左键拖动 | 框选放大 |
| 滚轮 | 以光标为锚点缩放 |
| 双击 | 还原预设范围 |

左键已被框选占用，中键是干净的平移触发键。

## 方案选择

采用 **方案 A：扩展现有 dragState**（已批准）。在现有 mousedown/mousemove/mouseup 事件链上按鼠标键位分支，中键（`button === 1`）进入平移模式，左键框选逻辑不变。改动集中（约 50 行），与现有交互零冲突，复用 `setView` 与重绘。

未采用的方案：
- 独立平移事件链：逻辑重复，两套边界处理难维护。
- 重构为 Pointer Events：改动面大，超出本次需求。

## 交互设计

1. **进入/退出平移**
   - 中键在绘图区内按下：`dragState = { mode: 'pan', startX, viewStart, viewEnd }`（记录按下时像素 x 与当时视图窗口）
   - 松开中键（`window` mouseup 兜底）：结束平移，清空 dragState
   - `mousedown` 时 `preventDefault()`，阻止 Windows 浏览器中键自动滚动
2. **移动语义**（拖动纸张感，与通达信/同花顺/东财一致）
   - 向右拖 → K 线右移，露出更早的历史（窗口左移）
   - 向左拖 → 看到更近的数据（窗口右移）
3. **换算**：根数位移 = 像素位移 ÷ 当前单根 K 线宽度（绘图区宽 ÷ 可见根数）；新窗口 = 按下时窗口 ± 位移
4. **边界**：clamp 到 `[0, 总根数]`，不可拖出数据范围；`MIN_BARS = 10` 最小可见根数约束不受影响（平移不改变窗口宽度）
5. **视觉反馈**
   - 平移中：隐藏十字光标与 tooltip，光标样式 `grabbing`
   - 非平移状态不变
6. **联动**：主图/副图/成交量同画布共享 `viewStart/viewEnd`，天然联动

## 实现要点

改动集中在 `web/static/js/kline_chart.js`：

- `dragState`（约 L241）：增加 `mode` 字段，`'select'`（默认，兼容现有逻辑）/ `'pan'`
- `mousedown`（约 L354）：新增 `button === 1` 分支，绘图区内才启动平移
- `mousemove`（约 L408）：`mode === 'pan'` 时按换算更新 `setView`，跳过十字光标绘制
- `mouseup`（约 L369）：`mode === 'pan'` 时仅清状态，不触发框选放大
- `mouseleave`（约 L525）：平移中移出不强制结束，由 `window` mouseup 兜底

## 测试要点

- 中键左右拖动：方向语义正确、窗口 clamp 不越界、主/副图联动
- 中键拖动中：十字光标与 tooltip 隐藏，光标为 grabbing
- 浏览器中键自动滚动未被触发
- 左键框选、滚轮缩放、双击还原回归正常
- 拖动中在画布外松开：平移正常结束，无卡死
